DÚVIDAS

O que você precisa saber.

De onde vêm os leads?

No modo real, o backend consulta uma API de dados de empresas/locais autorizada e normaliza os resultados. O projeto inclui um modo demo para testar a interface sem API.

A ferramenta garante que a empresa não tem site?

Não. A ausência de site deve ser tratada como um sinal de oportunidade e validada com os dados da fonte antes da abordagem.

Posso trocar os textos e os links da Cakto?

Sim. Os links ficam centralizados no JavaScript para você substituir pelos seus checkouts reais.
